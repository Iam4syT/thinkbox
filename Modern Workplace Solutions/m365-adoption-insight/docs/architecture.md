# Data flow and boundaries

Analysts need to distinguish a change in tool usage from improved colleague outcomes. Public Microsoft reporting documentation and the advertised service/adoption duties support the topic. The fictional cohorts and thresholds are a design hypothesis, not an employer policy.

Each row is one fictional cohort/service pair. Compare equal 30-day windows; use a small-cohort suppression floor of 5 in both windows. This is a learning safeguard, not a guarantee of anonymity or an employer rule. Activity can reflect role needs, report lag or shared-device patterns; it is not productivity.

Local CSV input is untrusted. Validation rejects malformed counts and windows and duplicate keys. JSON encoding treats strings as data. No identity provider, tenant connection, email sender or privileged operation exists. Human review owns decisions.
