# Microsoft 365 support change review

An independent synthetic local exercise for recurring workplace support. Status: implemented and locally evaluated20 October 2026; live Microsoft integration unrun.

Run from this folder using Python3.11+: `python3 -B -m unittest -v`, then `python3 -B main.py --output report.json`. Standard library only; no keys or paid resources. Open the report and compare it with [LAB.md](LAB.md).

[Evaluation](EVALUATION.md) · [Demo](DEMO%20SCRIPT.md) · [Contribution scope](CONTRIBUTIONS.md). The report proposes human review and never authorises tenant changes. No legal/client data, real support-system integration, candidate production claim or measured business saving.
