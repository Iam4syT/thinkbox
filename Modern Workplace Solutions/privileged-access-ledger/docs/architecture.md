# Architecture and handover
Synthetic JSON → schema checks → deterministic rules → JSON report → human review.
No credentials, network calls or write adapter. A report cannot authorise a change. Outputs describe supplied evidence, whose truth cannot be independently verified by the program. Keep real exports in approved private storage; these fixtures are not an upload route.
Operator: identity support engineer. Review faults with authorised directory/role owner, capture decision and source time, re-export after a separately approved change and compare. Escalate ambiguity rather than guessing. Do not schedule automatic changes.
