# Governed AI workshop scenario

Use a small synthetic scenario to make customer assumptions and review needs visible. Independent learning work; no commissioned deployment or live Microsoft integration.

## Run the example
Python 3.11 or later; standard library only. Open this exact project/scenario folder inside a Thinkbox clone. Run `python3 main.py data/workshop.json`, then `python3 -m unittest discover -s tests -v`. Read [LAB.md](LAB.md) for full steps, expected values, failures and cleanup. No credentials or paid service required.

## Scope and evidence
Inputs are fictional. Results are local calculations or metadata review decisions. No measured customer saving, production security or personal independent implementation is established. Compare with a manual worksheet before adding AI. See [EVALUATION.md](EVALUATION.md), [CONTRIBUTIONS.md](CONTRIBUTIONS.md) and [demo](DEMO%20SCRIPT.md).
