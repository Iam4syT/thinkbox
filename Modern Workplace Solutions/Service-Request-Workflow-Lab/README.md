# Service request workflow
Independent synthetic learning prototype. No commissioned client work or live Microsoft integration.
Problem: practise a small repeatable application-support control before using it in an authorised sandbox. Python standard library only; run `python3 -B scripts/workflow.py` and `python3 -B -m unittest discover -s tests -v` from this folder. See LAB.md for prerequisites, normal and failure paths, native extension and cleanup.
The local implementation is a learning model. Tenant-dependent Power Platform and SQL Server steps are unrun. Caller identities in the workflow are simulated; SQLite is not SQL Server. No real complaint or staff data. AI does not improve the deterministic baseline here and is omitted. No time/cost savings measured.
