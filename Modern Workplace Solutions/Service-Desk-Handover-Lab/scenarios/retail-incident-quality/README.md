# Incident quality and safe handover
Independent retail IT learning scenario. Daily incident logging, prioritisation, evidence and next-update handovers. Fictional records, read-only Python checks; no ServiceNow connection or physical test.
Run Python 3.11+ from this folder: `python3 scripts/incident.py templates/sample.json`, then `python3 -m unittest discover -s tests -v`.
Read [LAB.md](LAB.md), [evaluation](EVALUATION.md), [demo](DEMO%20SCRIPT.md), [architecture](docs/architecture.md) and [contribution](CONTRIBUTIONS.md). No packages, cloud account or API spend. Native and personal learning work remain separate.
