# Multi-site office ticket diagnosis

Independent, Codex-assisted learning scenario. Source and local tests work with fictional JSON only; learner reproduction and Windows/physical stages remain unrun. No employer commissioned it.

## Start
Use Python 3.10+ with no extra packages. Open a terminal in this scenario folder. Run:

```sh
python3 -m unittest -v
python3 solution.py sample.json learner-result.json
```

See [the granular lab](LAB.md), [actual evaluation](EVALUATION.md), [demo](DEMO%20SCRIPT.md), [contributions](CONTRIBUTIONS.md) and [architecture](ARCHITECTURE.md). Twelve behavioural test methods passed in the recorded Codex run. This small fixture is not production validation or evidence of the learner’s independent skill.
