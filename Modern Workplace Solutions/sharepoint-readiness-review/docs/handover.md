# Owner handover template

Use a private copy for actual records. This template does not invent teams or close findings.

| Field | Record |
|---|---|
| Review scope and source window | Include capture/report age and completeness |
| Source reference | Official observation or synthetic fixture |
| Finding and actual evidence | Separate observation from inference |
| Intended business task | Explain why the object/service is used |
| Accountable owner | Confirm with the organisation |
| Decision and next check | Record who approves and what closes the issue |
| Access/content verification | Actual identity checks and computed hashes where relevant |
| Unknowns and exclusions | Keep uncollected objects and untested features visible |
| Disposition and recheck date | Pending, accepted with limits, or escalate |

A handover is complete only when the next reader can identify the owner, source, limit and next action. No automatically generated finding is permission to modify the tenant.
