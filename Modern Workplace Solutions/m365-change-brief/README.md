# Change Brief Check

A small offline learning tool for repeated workplace-service review. Fictional records; no employer integration.

## Run

From this project folder with Python 3.10+:

```sh
python3 scripts/check.py templates/sample.csv 2026-10-25
python3 -B -m unittest discover -s tests -v
```

Expected: JSON output and 7 passing tests. No packages, licence or credentials are needed.

## What it demonstrates

Strengthens change planning, risk tracking and colleague guidance. Support documentation and peer teaching are adjacent skills; enterprise change-process ownership and organisation-wide training need separate evidence.

Manual review is the baseline; AI adds no clear value to this bounded rule check. No real business impact is claimed.
