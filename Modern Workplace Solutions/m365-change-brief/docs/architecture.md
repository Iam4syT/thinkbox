# Data flow and boundaries

Service owners need to turn release notices into clear actions with a named reviewer. Microsoft Message center documentation and the advertised release/communications duties support the topic. This fictional queue does not reproduce an employer process.

Each row is a fictional change. ISO dates determine a review queue. A named owner and draft/approved flag describe fixture data only. Source review, business risk assessment, a pilot and organisational approval remain external to this script.

Local CSV input is untrusted. Validation rejects malformed dates and missing owners and duplicate keys. JSON encoding treats strings as data. No identity provider, tenant connection, email sender or privileged operation exists. Human review owns decisions.
