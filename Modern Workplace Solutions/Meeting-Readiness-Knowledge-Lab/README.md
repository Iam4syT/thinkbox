# Meeting Readiness
Independent synthetic support lab, built with AI assistance. Python standard library only, no network calls or live changes.

## Quick start
Run from this folder: `python3 scripts/search.py templates/cards.json audio`
Run checks: `python3 -m unittest discover -s tests -v`

The output checks supplied data, not actual devices, permissions or diagnoses. No production readiness or individual independent competence follows from fixture tests.
