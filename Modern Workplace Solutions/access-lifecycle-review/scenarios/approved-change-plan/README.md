# Workplace identity change planner

A small offline teaching exercise for a recurring workplace-engineering task. No live service, model or employer system is contacted. Python 3.11+, standard library only.

Run from this folder: `python3 scripts/main.py` then `python3 -m unittest discover -s tests -v`. Read [LAB.md](LAB.md) for full setup, expected results, break/fix and cleanup. [EVALUATION.md](EVALUATION.md) records actual checks and limits; [CONTRIBUTIONS.md](CONTRIBUTIONS.md) states assistance and reproduction status.
