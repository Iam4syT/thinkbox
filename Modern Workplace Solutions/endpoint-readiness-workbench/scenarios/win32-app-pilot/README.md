# Win32 application pilot

Test a small package contract before a limited Windows deployment and removal.

Independent workplace learning scenario. Offline Python fixture workflow implemented and evaluated by Codex; native Windows/Intune operations and learner reproduction remain unrun. No employer system, personal data or commercial outcome.

## Run
Python 3.11 or later; standard library only. From this folder run `python3 scripts/pilot.py templates/package.json` and `python3 -m unittest discover -s tests -v`. On Windows use `py -3` instead of `python3`.

See [LAB.md](LAB.md) for granular setup, expected results, break/fix and cleanup; [EVALUATION.md](EVALUATION.md) for actual results; [CONTRIBUTIONS.md](CONTRIBUTIONS.md) for authorship; [DEMO SCRIPT.md](DEMO%20SCRIPT.md) for walkthrough.

Rules are the simple baseline. AI is unnecessary for this small deterministic task and cannot authorise a change. Native actions require a disposable personally controlledWindowsdevice and appropriate licences/authority. This tool does not prove production competency.
