# Scenario model assumptions

The cost service uses illustrative USD/kWh and kg CO2e/kWh coefficients retained from the earlier demo. The earlier broad IEA/IRENA attribution did not identify exact source tables or applicable geography/conditions; those numbers are not presented as verified sourced estimates. Demand percentage is mapped to demand × 10 kWh for arithmetic, without a measured time interval.

JUnit verifies arithmetic and relative ordering under these chosen constants. It does not measure real savings or validate industrial switching. The most-selected source is not necessarily the most efficient. Real operating recommendations require calibrated sensors, system constraints, time/energy accounting and justified rates.
