# Support Triage Workbench
An independent synthetic support learning project, created with Codex assistance. Not commissioned by an employer; no live customer/provider system. Intended user: support engineer practising a repeated diagnostic or triage task.

## Run
Python 3.11+; standard library only. From this folder run `python3 -m unittest discover -s tests -v` then `python3 src/main.py`. Read [LAB.md](LAB.md), [EVALUATION.md](EVALUATION.md) and [DEMO SCRIPT.md](DEMO%20SCRIPT.md).

## Scope
Rules baseline with simulated suggestions; no live AI model, Slack or status-page integration. Human judgement and personal reproduction remain necessary. No customer impact, timing gain or production capability claimed.
