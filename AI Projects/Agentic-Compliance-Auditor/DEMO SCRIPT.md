# Short demo — Draft policy-assessment lab

1. **Problem:** Explore a structured model suggestion against a small set of sample communication policies.
2. **Implementation:** open `main.py` and explain the main input, decision and output. State your own contribution using CONTRIBUTIONS.md.
3. **Run:** use the README's local command. Show the actual output rather than an invented screenshot.
4. **Check a limit:** No legal/regulatory certification or automatic approval. Local tests mock the provider; live model false-approval and false-rejection rates remain unmeasured.
5. **Evidence:** open EVALUATION.md and the linked results. Explain the baseline and what this check can and cannot establish.
6. **Next test:** identify one practical change that would improve confidence for a real workplace scenario.

Aim for about two minutes. Do not claim production use, savings or authorship that the evidence does not establish.
