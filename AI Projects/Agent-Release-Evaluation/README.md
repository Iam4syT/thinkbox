# Agent trace and release evaluation

A synthetic legal-workflow learning package. Decide whether an AI workflow meets explicit quality, cost and safety gates. Status: offline implementation evaluated; live AI/Azure/MCP and personal learner demonstration pending.

Run from this folder: python3 -B main.py and python3 -B -m unittest discover -s tests -v. Standard-library only. Read LAB.md for granular setup, failure recovery and cleanup; EVALUATION.md for exact limits.

The baseline deliberately uses no LLM. Potential AI extensions require an approved service, data and budget and a same-set comparison. No legal advice, client deployment or measured business impact.
